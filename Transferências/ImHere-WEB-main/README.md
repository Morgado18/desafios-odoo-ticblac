# 🚀 Im-here (Web)

**Im-here** é uma plataforma desenvolvida com **Next.js (App Router)** para conectar clientes a profissionais especializados, oferecendo funcionalidades completas de **gestão**, **comunicação em tempo real** e **pagamentos integrados**.

---

## 🛠️ Tecnologias Utilizadas

| Biblioteca / Serviço      | Finalidade                                                             |
|---------------------------|------------------------------------------------------------------------|
| **Next.js (App Router)**  | Estrutura moderna com melhor performance e organização                 |
| **Zustand**               | Gerenciamento de estado leve e eficiente                               |
| **React Query**           | Cache e sincronização de dados assíncronos                             |
| **shadcn/ui**             | Componentes acessíveis, elegantes e customizáveis                      |
| **React Hook Form**       | Controle de formulários de alta performance                            |
| **Zod**                   | Validação segura de dados com TypeScript                               |
| **Supabase**              | Banco de dados e comunicação em tempo real               |
| **Pusher Beams**          | Notificações push em tempo real diretamente para os dispositivos       |

## 🧪 Como Executar Localmente

### 1. **Clone o repositório:**
   ```bash
   git clone git@github.com:jonasportugall/ImHere-WEB.git
   cd ImHere-WEB
   ```

### 2. **Instale as dependências:**
   ```bash
   npm install
   # ou
   yarn install
   ```

### 3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   # ou
   yarn dev
   ```

### 4. **Acesse no navegador:**
   ```
   http://localhost:3000
   ```

## 🤝 Contribuindo

### 1. Crie uma nova branch:
```bash
# Para novas funcionalidades
git checkout -b feat/nome-da-feature

# Para correções de bugs
git checkout -b fix/nome-da-correcao
```

### 2. Valide o código antes de abrir PR:
```bash
npm run build   # Verifica erros de compilação
npm run lint    # Checa padrões de código
```

### 3. Commit e envio das alterações:
```bash
git add .
git commit -m "feat: adiciona sistema de chat básico"
git push origin sua-branch
```

- Descreva as mudanças realizadas
- Adicione screenshots (se aplicável)
